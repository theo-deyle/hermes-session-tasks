  <action>
Write the tests first and run them to see them fail. Then implement in `markdown.py`.

Escape rule (orchestrator decision 4). Define the module constant `ESCAPED_HASH = re.compile(r"^\\*#[0-9]+(?:\s|$)")`: zero or more backslashes, then `#`, then one or more ASCII digits, then whitespace or the end. `render` adds one backslash before text that matches it. With `include_ids` on, the id token comes first and the text after it is escaped the same way. Keep the plan 01-02 render rules: two-space subtask indent (D-04), lowercase `[x]`, final newline, empty board gives an empty string.

`parse(text: str) -> ParseResult`:
- Run `text.expandtabs(4)`, then `str.splitlines()` so CRLF works.
- Thematic break check first. A line that matches `THEMATIC_BREAK = re.compile(r"^\s{0,3}(?:(?:\*\s*){3,}|(?:-\s*){3,}|(?:_\s*){3,})$")` gives no item and changes no count. Without this check the item pattern reads `* * *` as a bullet with text `* *`.
- Item line: match `ITEM_LINE = re.compile(r"^(\s*)[-*+]\s+(?:\[([ xX])\](?=\s|$)\s*)?(.*)$")`. Group 1 is the indent, group 2 the box mark, group 3 the text. The lookahead `(?=\s|$)` accepts a box at the end of the line, so `- [ ]`, `- [x]` and `- [X]` with nothing after the box give empty text, which is skipped and counted in `skipped_empty` (D-09). Do not copy the RESEARCH pattern, which needs whitespace after the box and imports an empty `- [ ]` as text `[ ]`. `- [ ]foo` fails the lookahead, so the line is a plain bullet with text `[ ]foo`. No box means unchecked (D-08). Uppercase `X` means checked.
- Ignore every other line: headings, paragraphs, numbered lists and blank lines.
- On the text: strip one leading id token that matches `ID_TOKEN = re.compile(r"^#([0-9]+) ")` (D-05). Keep the number as `hint_id` when the run has at most 18 digits, else set `hint_id` to None; the token strips in both cases. This keeps `int()` far below the Python limit of 4300 digits, so a pasted digit run cannot raise. Then, when the text starts with a backslash and matches `ESCAPED_HASH`, remove exactly one backslash. Then run `model.sanitize_text`.
- Empty after sanitising: skip the line and count `skipped_empty` (D-09). Over `MAX_TEXT_CHARS` code points: skip and count `too_long`. Never truncate.
- Nesting by indent column with a stack. Pop entries while the top indent is greater than or equal to the line indent. Depth is the stack size after popping. Depth 0 is top-level. Depth 1 is a subtask of the depth-0 entry. Depth 2 or more is a subtask of the nearest depth-0 entry and counts in `moved` (D-02). An indented first line is top-level.
- A skipped line still goes on the stack as a placeholder. A line whose depth-0 entry is a placeholder becomes top-level, so no child attaches to the wrong parent.
- Return frozen dataclasses: `ParsedItem(text: str, checked: bool, hint_id: int | None, children: tuple[ParsedItem, ...])` and `ParseResult(items: tuple[ParsedItem, ...], moved: int, skipped_empty: int, too_long: int)`.

Keep functions under 50 lines. Split `parse` into a line matcher, a text cleaner and a tree builder.

In `markdown.py` add `ImportPlan(ops: tuple[AddItem, ...], overflow: int)` as a frozen dataclass, and `plan_import(result: ParseResult, capacity: int) -> ImportPlan`:
- Raise `ValueError` for a negative capacity.
