Step 3 - Core package `plugin/session_tasks/`. Standard library only. No Hermes import at module level. No module-level mutable state.
- `__init__.py`: one docstring line. No imports.
- `model.py` - board types and rules, no I/O. Write every symbol in the interfaces block. `utc_now()` returns `datetime.now(UTC).isoformat(timespec="microseconds")` with `+00:00` replaced by `Z`. `display_order` sorts top-level items by (position, id) and puts each item's subtasks right after it, also by (position, id). `sanitize_text` maps every `str.isspace()` character to a space, then drops every character whose `unicodedata.category` is `Cc`, `Cf`, `Cs` or `Co`, then returns `" ".join(result.split())`. Use this order, not the order in research rule 9: dropping a zero-width character after the collapse can leave a double space, so the function would not be idempotent. `clean_text` sanitises, raises `EmptyText` for an empty result and `TextTooLong` when `len(text) > MAX_TEXT_CHARS`. Length counts Unicode code points; do not normalise the text. Newlines collapse to one space (D-09). Each error carries `op_index`.
- `db.py` - `write_txn(conn)` runs `BEGIN IMMEDIATE`, yields, then `COMMIT`. On any `BaseException` it runs `ROLLBACK` when `conn.in_transaction` and re-raises. `read_txn(conn)` runs a deferred `BEGIN` so a board and its items come from one snapshot, then `COMMIT`, with `ROLLBACK` on error.
- `schema.py` - `SCHEMA_V1` holds one statement per entry, copied from RESEARCH "Recommended schema (v1)": tables `boards`, `items`, `aliases`, `changes` and index `items_by_parent`. Keep `agent_seen_rev` and `forked_from` (research A5). `migrate(conn)` reads `PRAGMA user_version` outside a transaction. Equal to `SCHEMA_VERSION`: return. Above it: raise `SchemaTooNew`. Below it: enter `write_txn`, read the version again, run each statement with `conn.execute`, then `PRAGMA user_version = 1`. Never call `executescript`, because it commits the open transaction first. `open_db(connect)` is a context manager: call `connect()`, set `conn.isolation_level = None`, run `PRAGMA foreign_keys=ON`, run `migrate`, yield, and close the connection in `finally`.
- `rows.py` - parameterised SQL with `?` only, explicit column lists, table names as constants. Write every function in the interfaces block. `read_items` maps tuples to `Item` (convert `checked` to `bool`) and returns `display_order(...)`. `next_position` returns 0 when the sibling group is empty, else max position plus 1. `create_board` inserts rev 0 and next_item_id 1.
- `aliases.py` - `get_alias` and `put_alias`. `put_alias` uses `INSERT OR IGNORE`, so the first alias wins and an alias never moves.
- `store.py` - `BoardStore`. `get_board(root_id)` opens with `schema.open_db`, reads inside `read_txn`, and returns `Board(root_id, 0, 1, ())` when no row exists. It never writes. `apply(root_id, ops, *, actor, base_rev)` opens with `open_db` and does all work inside one `write_txn`. When the board row is absent, call `rows.create_board` and `aliases.put_alias(conn, root_id, root_id)` in the same transaction. In this task apply handles a batch of top-level `AddItem` ops: `clean_text` each text, take the id from `next_item_id` (D-03), take `next_position`, insert the item with `rev = new_rev`, `updated_by = actor` and `created_at = updated_at = clock()`, and write one `Change(op="add", text=...)` row. Then `save_board` with `rev + 1` and the new `next_item_id`. Return `Applied` with the board read inside the same transaction. Raise `NotImplementedError` for other op kinds and for a parent; plan 01-02 replaces that branch.
- `markdown.py` - `render(board, *, include_ids)`. One line per item in `board.items` order. Top-level line: `- [ ] ` or `- [x] `. Subtask line: two spaces first (D-04). With `include_ids`, write `#<id> ` after the checkbox (D-04). Without it, write no id (D-05). End with one newline. An empty board renders as an empty string. Plan 01-03 adds the escape rule and the parser.
- `lineage.py` - the Protocol, `ReaderFactory`, `ResolutionKind`, `Resolution` and `SessionResolver` from the interfaces block. `resolve(session_id)` raises `InvalidSession` for a non-str id or an id that is empty after `strip()`. Never strip a valid id. Alias hit: return `Resolution(root, "plain")` when root equals the id, else `"compression"`, and open no reader. Alias miss: open one reader with `self.open_reader()` and close it in `finally`. Take `lineage = reader.get_compression_lineage(session_id)`. The root is `lineage[0]`, or the id itself when the list is empty. Kind is `"compression"` when the root differs from the id (D-07). When the kind is compression and the root has a board row, write the alias inside `write_txn`. Plan 01-04 adds fork, delegate, missing-row and missing-state.db handling.
- `paths.py` - `connect()` imports `plugin_db` from `plugins.plugin_storage` inside the function, with `# pyright: ignore[reportMissingImports]`, and returns `plugin_db(PLUGIN_NAME)`.
