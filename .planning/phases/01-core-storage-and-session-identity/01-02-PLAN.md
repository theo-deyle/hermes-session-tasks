- `model.py` - board types and rules, no I/O. Write every symbol in the interfaces block. `utc_now()` returns `datetime.now(UTC).isoformat(timespec="microseconds")` with `+00:00` replaced by `Z`. `display_order` sorts top-level items by (position, id) and puts each item's subtasks right after it, also by (position, id). `sanitize_text` maps every `str.isspace()` character to a space, then drops every character whose `unicodedata.category` is `Cc`, `Cf`, `Cs` or `Co`, then returns `" ".join(result.split())`. Use this order, not the order in research rule 9: dropping a zero-width character after the collapse can leave a double space, so the function would not be idempotent. Category `Cf` includes U+200D (zero-width joiner) and the tag characters U+E0020 to U+E007F. A multi-part emoji joined by U+200D is therefore stored as its parts with no joiner, and a single-code-point emoji is stored unchanged. State this joiner rule in the `sanitize_text` docstring. `clean_text` sanitises, raises `EmptyText` for an empty result and `TextTooLong` when `len(text) > MAX_TEXT_CHARS`. Length counts Unicode code points; do not normalise the text. Newlines collapse to one space (D-09). Each error carries `op_index`.
- `db.py` - `write_txn(conn)` runs `BEGIN IMMEDIATE`, yields, then `COMMIT`. On any `BaseException` it runs `ROLLBACK` when `conn.in_transaction` and re-raises. `read_txn(conn)` runs a deferred `BEGIN` so a board and its items come from one snapshot, then `COMMIT`, with `ROLLBACK` on error.
- `schema.py` - `SCHEMA_V1` holds one statement per entry, copied from RESEARCH "Recommended schema (v1)": tables `boards`, `items`, `aliases`, `changes` and index `items_by_parent`. Keep `agent_seen_rev` and `forked_from` (research A5). `migrate(conn)` reads `PRAGMA user_version` outside a transaction. Equal to `SCHEMA_VERSION`: return. Above it: raise `SchemaTooNew`. Below it: enter `write_txn`, read the version again, run each statement with `conn.execute`, then `PRAGMA user_version = 1`. Never call `executescript`, because it commits the open transaction first. `open_db(connect)` is a context manager: call `connect()`, set `conn.isolation_level = None`, run `PRAGMA foreign_keys=ON`, run `migrate`, yield, and close the connection in `finally`.
