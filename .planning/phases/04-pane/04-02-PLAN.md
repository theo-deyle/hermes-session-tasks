New contracts (the later plans rely on these exact names):

Config keys
- `restSequences`: map of path to a list. Each call to that path takes the next entry: a reply body, `"__error__"` (reject with `500: forced failure`) or `"__relay__"` (forward to the relay). An empty list falls back to `restOverrides`, then to the relay.
- `duringWrite`: list of steps. They run once, inside the first POST call, before it is forwarded. The harness then waits until no other rest call is pending (the held POST counts as one) before the `atWrite` capture.

Step kinds
- `{"click": "<label>"}` or `{"click": {"label": "<label>", "row": "<id>"}}`: the Button whose `aria-label`, or else its text children, equals the label. Zero matches, two or more matches, or a disabled match throws.
- `{"clickText": "<text>"}`: the host element with an `onClick` whose direct text equals the text.
- `{"check": {"row": "<id>", "value": true}}` (from 04-01).
- `{"type": {"input": <selector>, "text": "..."}}`: `onChange({target: {value: text}})`.
- `{"key": {"input": <selector>, "key": "Enter"}}`: `onKeyDown({key, preventDefault() {}, nativeEvent: {isComposing: false}})`. With `"blur": true` in the object, the harness then calls `onBlur({})` of the same Input record before it settles (a browser can fire blur when the focused input goes away after Enter or Escape).
- `{"blur": <selector>}`: `onBlur({})`.
- `{"confirm": true}` and `{"cancel": true}`: `onConfirm()` or `onClose()` of the open ConfirmDialog; none open throws.
- `{"focus": "<sid>"}` or `{"focus": null}`: the focused session the next render reads.
- `{"event": {...}}` (kept).
- `{"outside": {"session_id": "s1", "ops": [...], "base_rev": 1}}`: a POST to `baseUrl + '/board/edit'` with `fetch`, not recorded in `restCalls`; `session_id` defaults to the focused session; `{body, reply}` goes to `outsideCalls`; a non-2xx reply throws.
- `{"timers": true}`: runs every pending `ctx.setTimeout` callback whose cleanup was not called, in call order.
- Input selector: an object with `placeholder` and or `row`; it must match exactly one Input.

Output keys (added)
- `inputs`: `{placeholder, row, value, readOnly, disabled, maxLength, size, autoFocus}`
- `buttons`: `{label, row, disabled, className}` (replaces the label-only list)
- `checkboxes`: adds `guarded`
- `confirm`: null, or the last ConfirmDialog rendered: `{open, title, description, confirmLabel, cancelLabel, destructive}`
- `copy`: null, or the last CopyButton: `{text, disabled, label, appearance}` (`text` is the function result when `text` is a function)
- `tips`: Tip labels in render order
- `nodes`: one per host element with direct string children: `{text, className, style, row, scroll}`; `scroll` is true inside a ScrollArea
- `timeouts`: ms values of every `ctx.setTimeout` call
- `outsideCalls`: `{body, reply}` per outside step
- `atWrite`: one `{lines, checkboxes, inputs}` per POST
- EmptyState `title` and `description` appear in `lines` and `nodes`

tests/pane_rig.py (added)
- `PROBE_JS = ROOT / "tests" / "fixtures" / "harness_probe.js"`
- `harness_error(config, tmp_path, plugin=PLUGIN_JS) -> str`: runs the harness, asserts a non-zero exit, returns stderr
- `inputs(result, placeholder=None, row=None) -> list[dict]` and `the_input(result, placeholder=None, row=None) -> dict` (asserts exactly one)
- `button(result, label, row=None) -> dict` (asserts exactly one)
- `stale_body(board: Board, root_id: str) -> dict`: a stale reply body in the D-22 shape built with `board_json.board_dict`
