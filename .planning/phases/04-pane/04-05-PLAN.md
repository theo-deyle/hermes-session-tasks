plugin/session_tasks/markdown.py: `render(board, *, include_ids)` gives one line per item, `- [ ] text` or `- [x] text`, two spaces before a subtask line, a newline after every line; `ESCAPED_HASH = ^\\*#[0-9]+(?:\s|$)` gets one leading backslash. `BoardStore.get_board` returns items in display order (rows.py), the same order the route sends.

Seeding subtasks in a test: `store.apply("s1", [AddItem("Plan trip"), AddItem("Book flight", checked=True, parent_ref=0), AddItem("Pack", parent_ref=0)], actor="agent", base_rev=0)` gives ids 1, 2, 3.

Harness (plan 04-02): `click` with row, `check`, `focus`; output `nodes` (text, className, style, row, scroll), `buttons` (label, row), `tips`, `copy` (text, disabled, label, appearance), `checkboxes`; EmptyState lines.

UI-SPEC copy used here: `{open} of {total} open`, `{done}/{total}`, `The agent adds items here.`, `Add one below.`, `Open a chat to see its items.`, `Collapse subtasks`, `Expand subtasks`, `Copy as markdown`.

New contracts (plugin/desktop/plugin.js):
- `buildTree(items)`: a list of `{item, children}` in board order (items arrive with each subtask after its parent)
- `subtaskCountText(children)`: `{done}/{total}`
- `boardMarkdown(items)`: the copy text
- `ItemBlock` (stateless): one top-level item: a `div` with `data-item-id` of the parent that holds the parent row, then each subtask row (own `div` with its own `data-item-id`), and the slot plan 04-06 fills with the subtask add line
- `Pane` state `collapsed` (an object keyed by item id)
</interfaces>
