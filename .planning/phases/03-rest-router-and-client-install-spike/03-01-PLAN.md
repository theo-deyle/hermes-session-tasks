Output: `nudge.py`, `make_pre_llm_call`, the `pre_llm_call` registration and manifest line, the hook tests, and `tests/live/own_job/`.

- `plugin/session_tasks/tool_text.py` - holds `NUDGE_LINE`, next to the other static model-facing text. It is the one module the todo-mention guard skips, so a later wording round may name the boundary if it needs to.

Plan 03-07 records the measured turn counts.
