<interfaces>
Existing contracts this plan changes:
- `board_tools.BoardTools.after_write` is `Callable[[str], None]` today and gets `root_id` only (board_tools.py lines 26, 34, 80). It becomes `WriteListener` and gets `(root_id, session_id, rev)`, where rev is `Applied.rev`.
- `board_api.BoardApi` (plan 03-02) gains `after_write: WriteListener = _no_listener`. `board_api.build(...)` gains `publish: events.Publisher = events.publish`.
- `wiring.register(ctx, *, connect, open_reader)` gains `publish: events.Publisher = events.publish`.
- Hermes: `broadcast_plugin_event(plugin_id: str, event: str, payload: dict | None)` builds `plugin.<plugin_id>.<event>`, logs and returns when no gateway runs, and never raises in that case (RESEARCH Answer 3).

New contracts:

events.py
- `PLUGIN_ID = paths.PLUGIN_NAME` (`"hermes-session-tasks"`), `EVENT = "board.updated"`
- `Publisher: TypeAlias = Callable[[str, str, int, Actor], None]` - (root_id, session_id, rev, actor)
- `WriteListener: TypeAlias = Callable[[str, str, int], None]` - (root_id, session_id, rev)
- `def publish(root_id: str, session_id: str, rev: int, actor: Actor) -> None`
- `def listener(actor: Actor, publisher: Publisher = publish) -> WriteListener`
</interfaces>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| serve process to Desktop clients | The broadcast goes over the authenticated gateway socket to every Desktop client of that process. |
| write path to listener | A listener runs after a committed write in the same thread. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-13 | Information Disclosure | events.publish payload | medium | mitigate | The payload holds session_id, root_id, rev and actor only. `test_payload_holds_no_text` fails on any item text. |
| T-03-14 | Denial of Service | after_write listeners | medium | mitigate | The publish runs after the commit, never inside the write transaction, so a slow socket write (up to 10 s, RESEARCH Answer 3) holds no lock. Every fault is caught and logged. |
| T-03-15 | Repudiation | actor field | low | mitigate | The tool path binds actor agent and the route path binds actor user in wiring and build; tests check both. |
| T-03-SC | Tampering | npm/pip/cargo installs | high | mitigate | No package install in this plan. |
</threat_model>
