Planner choices inside D-37 (record them in the SUMMARY):
1. The alias delete also removes alias rows whose root id is in the list (RESEARCH addition). It never removes a board by an alias match.
2. A missing or non-string `reason` removes nothing. D-37 lists what each reason does; an unreadable payload is not a reason, so the safe action is none.

Not in scope (D-37 and the deferred list): no sweep for orphan boards. A delete in a process that runs older plugin code, or while no Hermes process runs, leaves an inert board.

Purpose: STOR-07 (SC4). This plan integrates no external API; it uses the Hermes host hook contract.

In replies to Theo, call it "the board cleanup when a chat is deleted" (house rule 22).
