## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Public repo to a Hermes home | The CLI clones and runs code from GitHub into the plugin folder. |
| Scratch home to the real home | A wrong HERMES_HOME would change the live gateway's plugins. |
| devpc to the named host over SSH | Claude installs code and restarts the gateway on another machine of Theo's. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-16 | Tampering | real Hermes home | high | mitigate | HERMES_HOME under the scratchpad; refused when it resolves to ~/.hermes; real symlink and plugin line compared before and after; removal only after a path prefix check. |
| T-07-17 | Tampering | code installed from GitHub | medium | mitigate | The install revision must equal `git rev-parse main`; the CLI security scan runs at install; `plugins doctor` checks the registrations. |
| T-07-25 | Tampering and Denial of Service | Hermes home and gateway of the named host | high | mitigate | The probe of Task 1 is read only; Task 3 acts only on the host in the `Proof host:` line, which Theo named after the question announced the restart; BatchMode SSH with the existing key, no new key; a taken plugin slot stops the task; the restart runs only when the gateway ran; no other process stops. |
| T-07-26 | Information Disclosure | host names in the SUMMARY, which goes public in plan 07-09 | low | mitigate | The SUMMARY names only the aliases where Hermes answered, never an IP address and never another alias; the push go of plan 07-09 names the SUMMARY files. |
