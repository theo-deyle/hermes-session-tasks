<objective>
Give the agent a session title for each board root, read through the same read-only door that Phase 1 uses for lineage. `board_sessions` (plan 06-08), the copy result (plan 06-05) and the cross-read result (plan 06-08) use it.

Purpose: TOOL-03 titles (D-39). The pane gets its titles from `session.list` instead (D-43, plan 06-04); this plan is the agent side only.

Assumption (RESEARCH A5, record in the SUMMARY): the first user message sits among the first 5 messages of the board root. When it does not, the label falls to `Untitled session`. RESEARCH also notes that the agent label and the pane label can differ by Hermes's `#N` title suffix on a compressed chain; both name the same session.

Python matrix (CLAUDE.md): every Python test this plan adds must pass on 3.11 and on 3.14. Wave 1 runs with plans 06-01, 06-02 and 06-04; task verify commands name only this plan's files. No new Hermes import: `SessionDB` already has both methods. This plan integrates no external API.

Output: titles.py, the widened SessionReader Protocol, the fake reader methods, tests/test_titles.py, and the real SessionDB parity check.

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-6-07 | Tampering | titles.TitleLookup, session_reader | high | mitigate | Reads go through `SessionDB(read_only=True)` only (layout guard `test_session_db_is_always_built_read_only`); the contract test asserts the state.db digest is unchanged after the title reads. |
| T-6-08 | Tampering | titles._label output | medium | mitigate | Every label goes through `sanitize_text` (no newline, no control or format character), and a message label is cut to 60 characters, so a title cannot forge a second result line. Tests: test_first_user_message_is_the_second_choice, test_message_title_is_cut_to_60_characters. |
| T-6-09 | Denial of Service | titles.TitleLookup.titles | medium | mitigate | One reader per call, closed in `finally`; any fault gives `Untitled session` and one WARNING and never fails the tool. Tests: the fault tests. |

No package install in this plan.
</threat_model>
