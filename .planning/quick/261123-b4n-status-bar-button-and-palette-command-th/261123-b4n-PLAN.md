# Quick task 261123-b4n: status bar button for the Session tasks pane

## Why

Theo reports that the Session tasks pane often is not on screen. The pane can sit behind another tab in its zone, the right column can be collapsed, or the pane can be hidden. The Desktop SDK has `host.revealPane(id)` for an explicit user action: it un-dismisses, un-hides, un-collapses the zone and fronts the tab. The contribution-scoped pane id is `<pluginId>:<paneId>` (`apps/desktop/src/sdk/index.ts`, `paneVisibility` and `revealPane`).

A status bar item is a declarative `StatusbarItem` (`apps/desktop/src/app/shell/statusbar-controls.tsx`): `icon`, `label`, `title`, `toggleLabel`, `variant: 'action'`, `onSelect`. `toggleLabel` lists it in the bar's right-click show/hide menu, as the built-in Webhooks and Terminal items do.

Limit: the tab's Close on the only pane of a plugin turns the plugin off (`closeTreePane` in `components/pane-shell/tree/store.ts`). The status bar item goes with it. The README already names the recovery path.

## Task 1: register the status bar item and the palette command

Files: `plugin/desktop/plugin.js`

- Import `Codicon` and `PALETTE_AREA` from `@hermes/plugin-sdk`.
- Add `PANE_KEY = 'pane'`, `PANE_ID = PLUGIN_ID + ':' + PANE_KEY`, `SHOW_LABEL`, `SHOW_TITLE`, `SHOW_TOGGLE_LABEL`, `SHOW_COMMAND`.
- Add `showPane()`: when `typeof host.revealPane === 'function'`, call `host.revealPane(PANE_ID)`.
- In `register(ctx)`, after the pane, register `{ id: 'show', area: 'statusBar.right', order: 90, data: { id: PANE_ID + '-show', icon, label, title, toggleLabel, variant: 'action', onSelect: showPane } }` and `{ id: 'show-command', area: PALETTE_AREA, data: { id: 'hermes-session-tasks.show', label, keywords, run: showPane } }`.
- Export `PANE_ID`, `SHOW_LABEL`, `SHOW_TITLE`, `SHOW_COMMAND`, `showPane` for the tests.

Verify: `node --check plugin/desktop/plugin.js`.
