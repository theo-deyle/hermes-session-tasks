# Quick task 261123-c04: cap the Session tasks pane width

## Why

Theo reports that the pane fills nearly the whole window, and that a drag on its edge snaps back.

The Desktop split renderer (`apps/desktop/src/components/pane-shell/tree/renderer/tree-split.tsx`, `allFixedAbsorberIndex` in `track-model.ts`) gives the leftover space of a row to the last fixed track that has no `maxWidth`, when every visible track in that row is fixed. That track grows past its size, and a sash drag only sets its start size, so it snaps back. The core sidebars avoid this with a `maxWidth` (sessions `360px`, review and files `20rem`). The Session tasks pane declares `width: '320px'` and no cap, so it is a valid absorber.

## Task 1: declare minWidth and maxWidth on the pane

File: `plugin/desktop/plugin.js`

- Pane `data` becomes `{ placement: 'right', dock: { pane: 'workspace', pos: 'right' }, width: '320px', minWidth: '240px', maxWidth: '40rem' }`.

Verify: `node --check plugin/desktop/plugin.js`.
