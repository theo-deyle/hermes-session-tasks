Step 1 - Write `scripts/check.sh` (bash, mode 755) from the RESEARCH block, with these additions:
- Start with `set -euo pipefail` and `cd "$(dirname "$0")/.."`.
- First run `uv run --no-project --python 3.11 -- python -I scripts/check_pins.py`.

- In each leg run: `uv sync --locked --python "$v"`, `uv run --python "$v" ruff check .`, `uv run --python "$v" ruff format --check .`, `uv run --python "$v" pyright --pythonversion "$v" --pythonpath "${UV_PROJECT_ENVIRONMENT}/bin/python"`, then `timeout 300 uv run --python "$v" pytest -q`.

Step 2 - Write `tests/home_guard.py`. It holds the snapshot helpers and the two session hooks, and imports only `os`, `sys`, `pathlib` and `pytest`:
- `WATCHED = Path("plugin-data") / "hermes-session-tasks"`. This is the only path under a Hermes home that this plugin writes (`plugin_db(PLUGIN_NAME)`). Watch no other path. The live gateway and other plugins create and remove entries elsewhere in `~/.hermes` during a run (verified on devpc 2026-10-30: `state.db-wal`, `gateway.lock`, `.update_exit_code.<uuid>`), so a guard there fails the run for entries that the run did not create.
- `real_home_roots() -> tuple[Path, ...]`: `Path.home() / ".hermes"`, plus the `HERMES_HOME` value when it is set and differs.
- `snapshot(root: Path) -> frozenset[str] | None`: None when `root / WATCHED` is not a directory. Else the path of that directory plus every entry at any depth under it, each relative to `root`. Skip a name that ends with `-wal`, `-shm` or `-journal`: once the plugin is deployed, the live gateway creates and removes these next to `data.db`, and a database that a test creates still shows as its main file. Read names only; never open a file.
- `new_entries(before, after) -> tuple[str, ...]`: the sorted paths in `after` that are not in `before`. None counts as empty.
- `pytest_sessionstart(session)`: store `{root: snapshot(root)}` for every root on `session.config.stash` under a module `StashKey`. This hook runs before any fixture, so the autouse `HERMES_HOME` fixture has not changed the environment yet.
- `pytest_sessionfinish(session, exitstatus)`: take each snapshot again. When `new_entries` is not empty, write `real Hermes home gained: <paths joined by ", ">` to `sys.stderr` and set `session.exitstatus = pytest.ExitCode.TESTS_FAILED`. pytest returns `session.exitstatus` after this hook, so the read-only gate depends on the run itself. A prototype of this design passed both session guard tests with pytest 9.1.1 on Python 3.11 and 3.14 (devpc, 2026-10-30).

Step 4 - Write `tests/fakes.py`. It imports no `session_tasks` module; the Protocol match is structural.
- `SessionSpec(parent: str | None = None, end_reason: str | None = None, model_config: dict | None = None, source: str = "desktop")`.
- `FakeSessionReader(specs)` mirrors Hermes per RESEARCH "Hermes API reference for lineage". `get_session` returns `None` for a missing id, else a dict with `id`, `source`, `parent_session_id`, `end_reason`, `model_config` as a JSON string (`None` when the spec has none), plus top-level `_branched_from` and `_reset_from` when present. It does not lift `_delegate_from`. `is_explicit_fork_child` is true when source is `"tool"` or the parent equals `_branched_from` or `_delegate_from`. `get_compression_lineage` returns `[]` for a missing id and `[id]` for a fork child. Otherwise it walks up while the parent exists, the parent `end_reason` is `"compression"`, and the child is neither a fork nor a reset child. Then it walks down to the tip and returns the list when the id is in it, else `[id]`. `close()` records that the reader closed.
- `FakeReaderFactory(specs)` is callable, counts opens, and keeps each reader so a test can assert every reader closed.

The guards cover the tests named in the behavior block.

The two session guard tests also live in `tests/test_layout.py`. Put `pytest_plugins = ["pytester"]` at the top of this file only.
