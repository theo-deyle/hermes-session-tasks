<objective>
Add the `board_copy` tool handler: it copies chosen items, or all open items, from another session's board into the calling session's board, and returns the D-42 sentence plus the new lines with their ids.

Purpose: TOOL-05 (D-40 to D-42). Registration, the schema and the tool text come in plan 06-10; the cross read and `board_sessions` come in plan 06-08. A copy is an add, so the D-18 guard does not apply and no hook guards it (D-40).

Python matrix (CLAUDE.md): every Python test this plan adds must pass on 3.11 and on 3.14. Wave 2 runs with plans 06-06 and 06-07; the task verify commands name only this plan's files. New tool tests go in tests/test_board_cross.py, because tests/test_board_tools.py is 590 lines (house ceiling 800). This plan integrates no external API.

Output: `BoardTools.board_copy`, the copy result texts, tests/test_board_cross.py.
</objective>

| T-6-16 | Repudiation | copy provenance | low | mitigate | Every copied item has a `copied` journal row naming the source root and item id (plan 06-01). |
